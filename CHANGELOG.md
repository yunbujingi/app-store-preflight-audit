# Changelog

All notable changes are documented here. The project follows Semantic Versioning after 1.0.

## 0.2.0-beta - 2026-08-30

- Added packaged Mach-O, architecture, dynamic dependency, signature, entitlement, and bundle-local required-reason evidence.
- Added reproducible StoreKit, account deletion, third-party AI, multi-target, Watch/Widget/Share, regional commerce, and negative-control eval fixtures.
- Added per-rule TP/TN/FP/FN/unknown/blocked metrics and configurable CI gates.
- Added stable schema `0.2.0`, backwards-compatible `0.1.0` fragment ingestion, SARIF 2.1.0, and JUnit output.
- Added hash-only Apple policy freshness/change records scoped by storefront and platform.
- Added non-mutating Simulator scenario planning and observation normalization.
- Added deterministic zip packaging, a dry-run-first no-overwrite installer, sample reports, release asset automation, and compatibility documentation.
- Added aligned English and Simplified Chinese READMEs plus bilingual repository and Skill UI metadata.
- Added PBX source/resource membership and optional `xcodebuild` metadata target graphs with stable source-to-product relations.
- Added safety-limited `.ipa` extraction, Xcode Privacy Report import, parent/child bundle/version/platform/architecture checks, embedded-profile comparison, debug-resource leads, and static-library attribution limits.
- Added fragment-wide absolute-path redaction, collector budgets, symlink/traversal defenses, executable hook detection, and capability/side-effect acknowledgement.
- Added a stable rule registry, local read-only App Store Connect export import, baseline diffs, expiring accountable suppressions, and community issue forms.
- Pinned GitHub Actions to full commit SHAs and removed destructive release asset clobbering.

## 0.1.0-beta - 2026-08-30

- Initial progressive Codex skill structure.
- Source, build, archive, and submission audit modes.
- Evidence, severity, disposition, and coverage model.
- Isolated Xcode runner with dry-run and Git mutation detection.
- Project, privacy manifest, and archive inventory scripts.
- Structured JSON schemas and Markdown report assembly.
- Synthetic eval fixtures, tests, CI, license, disclaimer, and security policy.
